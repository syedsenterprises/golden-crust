# Golden Crust Bakery — Baked at Dawn

Live demo site: a bakery with a working pickup-order builder.

**What actually works (in your browser, no server needed):**
- Menu split by category with live "Add" buttons
- Order panel with quantities, live total, and localStorage saving
- Pickup form (name, date, time) that confirms with an order reference

**Honest limits:** static front-end. No payment is taken and no order reaches
the bakery. Connect an ordering system to take real orders.
